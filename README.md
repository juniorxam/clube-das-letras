# Clube das Letras

Jogo educativo infantil para aprender letras, vogais e o som inicial de palavras.

## Como jogar

Abra o arquivo `index.html` em qualquer navegador moderno. O jogo funciona sem servidor e salva o recorde e as estrelas no navegador.

## Modos

- **Letras:** encontre a letra indicada.
- **Vogais:** pratique A, E, I, O e U.
- **Palavras:** identifique a primeira letra de palavras ilustradas.
